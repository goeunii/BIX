# 돈워리택스

소상공인들을 위한 세무 도움 웹/앱 Mockup

BIX 2026 세무 팀의 **발표용 웹 프로토타입**이에요. 질문 다섯 개에 답하면 낼 세금, 받을 수 있는 혜택, 마감일을 보여 줘요.

- PC에서는 왼쪽 메뉴, 폰에서는 아래 탭으로 바뀌어요 (반응형).
- 로그인·가입은 화면만 있는 가짜예요. 가입하면 그 브라우저에만 기억해요.
- 세금 계산은 TAX 모듈(`BIX2026/TAX`)의 계산 엔진을 그대로 써요. 계산 기준·근거·연도는 TAX 저장소 `근거/README.md`에 있어요.

## 파일
| 파일 | 하는 일 |
|---|---|
| `src.html` | 화면 원본 (여기를 고쳐요) |
| `build.py` | TAX 계산 엔진과 `data/` 자료를 `src.html`에 끼워 `index.html`을 만들어요 |
| `data/demo-core.json` | 데모 자료. Core의 해운대 바삭치킨·광안 소금빵 자료를 그대로 받아 둔 사본 |
| `data/wage-table-2026.json` | 근로소득 간이세액표 원본 (소득세법 시행령 별표2, 2026.2.27 개정) — 직원 원천세 계산용 |
| `tools/snapshot.py` | 배포된 사이트로 Core 자료를 다시 받아 `data/demo-core.json`을 새로 만들어요 (키 필요 없음) |
| `index.html` | 실제로 열리는 페이지 (자동 생성, 직접 고치지 않기) |
| `api/core.js` | Vercel 서버 함수. 팀 키를 서버에만 두고 Core에 대신 물어봐요 |
| `vercel.json` | 서버 함수 설정 |

## 고친 뒤 다시 만들기
```bash
python3 build.py              # 옆 폴더 ../TAX/index.html 의 엔진을 씀
git add -A && git commit -m "무엇을 바꿨는지 한 줄" && git push
```
push 하면 Vercel이 자동으로 새로 배포해요.

## 데이터는 어디서 오나요?
| 상황 | 데이터 |
|---|---|
| Vercel에 올리고 `CORE_KEY`를 넣었을 때 | **Core 실시간 자료** (시뮬레이션 가게만) |
| 키가 없거나, 파일로 열었거나, 주소 끝에 `?demo` | **데모 데이터** = Core 바삭치킨·소금빵 자료 사본 |

Core 자료가 바뀌면 데모 자료도 새로 받아요:
```bash
python3 tools/snapshot.py https://bix-phi.vercel.app && python3 build.py
```

서버 함수가 지키는 것:
- 읽기만 해요: `ping`, `tags.list`, `business.list`, `records.read`, `ai.ask`만 통과. `purchases.add`(저장) 등은 막아요.
- 시뮬레이션 가게(`is_sim`)만 보여 주고 읽게 해요.
- AI 질문: 600자 이하, 사진 1장, 답 길이 최대 4000토큰(AI가 생각하는 몫 포함), 접속한 곳마다 1시간 30번 (`AI_LIMIT_PER_HOUR`로 바꿀 수 있어요).

## Vercel에 올리기 (처음 한 번)
1. https://vercel.com 에 GitHub 계정으로 로그인
2. **Add New → Project** → 이 저장소(`goeunii/BIX`) **Import**
3. Framework Preset은 **Other** 그대로, 다른 설정은 건드리지 않기
4. **Environment Variables**에 추가
   - `CORE_KEY` = 세무 팀 키 (Core에서 받은 키. 코드·채팅·단체방에 붙여 넣지 말 것)
5. **Deploy** → `https://<프로젝트이름>.vercel.app` 주소가 생겨요. 이 링크를 누구에게나 보내면 돼요.

키를 바꾸려면 Vercel → Project → Settings → Environment Variables에서 고치고 **Redeploy** 해요.

## 발표 바로가기
| 주소 끝 | 화면 |
|---|---|
| `/` | 첫 화면 |
| `#/start` | 질문 시작 |
| `#/home` | 홈 대시보드 (샘플: 해운대 바삭치킨) |
| `#/tax/vat` · `#/tax/income` · `#/tax/wh` | 부가세 · 종합소득세 · 원천세 |
| `#/ben/now` · `#/ben/past` | 올해 혜택 · 작년에 놓친 혜택 |
| `#/docs/rc` · `#/docs/bank` | 영수증 정리 · 통장 내역 계정 분류 |
| `#/risk` · `#/report` | 위험 점검 · 세무사 보고서 |

상담은 왼쪽 메뉴(폰은 더보기)나 오른쪽 아래 버튼에서 열려요. **AI 상담**과 **세무사 상담**(접수 화면만, 실제로 보내지 않음) 창이 나뉘어 있어요.

## 계산 기준 (2026년)
- 부가세(일반): 재료는 품목별로 면세/과세를 나눠 매입가액 → 매입세액 → 합계로 보여 줘요. 의제매입세액은 한도(개인 음식점 과세표준 1억 이하 75%·2억 이하 70%·초과 60%)까지 계산하고, 카드매출 세액공제는 배달앱 결제분까지 넣어 1.3%(연 1,000만원)로 계산해요. 범위 대신 한 숫자로 보여 주고, 영수증 확인이 필요한 몫은 따로 적어요.
- 직원 원천세: 근로소득 간이세액표(2026.3.1 이후 지급분) 원본 표에서 월급·공제대상 가족 수·8~20세 자녀 수로 찾아요. 지방소득세 10%.
- 영수증: AI가 읽은 품목을 규칙으로 한 번 더 맞춰요(상표·용량 떼기, 가게가 자주 사는 품목 이름으로 묶기, 면세/과세). 틀리면 화면에서 바로 고쳐요.
- 통장: 받는 사람 이름으로 계정을 나누고, 사장님이 고치면 같은 이름 거래도 같이 바뀌어요. 애매한 건 AI에게 물어봐요. 파일은 브라우저에서만 읽어요.

계산은 참고용이며 신고 전 세무사 확인이 필요해요.
